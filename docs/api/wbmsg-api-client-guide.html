1. Getting started

  1. In the WBMSG dashboard open Settings › API Credentials. You need the Settings API permission (organization admins have it).
  2. Create a credential. You receive an Auth ID (a UUID) and an Auth Token. The token is shown once. Store it securely. You can rotate it at any time (the old token stops working immediately) or revoke the credential.
  3. Optionally set a status callback URL and an inbound URL on the credential. Both must be public https URLs.
  4. Your WhatsApp Business number and templates are your own, managed in WBMSG. Conversation charges are billed to you directly by Meta.

An organization can hold up to 10 active credentials. The Settings › API Usage page shows request counts, success and error rates per credential and per endpoint.

3. Send a message

POST/Message/
FieldNotes
srcYour connected WhatsApp Business number, digits only (for example 918269150291).
dstOne or more recipients in international format, separated by <. At most 20 per request. Duplicates are removed.
typewhatsapp
One of: text, media_urls, template, interactive, locationExactly one content field per request. Details below.
urlOptional status callback URL for this request. Overrides the credential's callback URL.
methodPOST (default) or GET: how the status callback is delivered.

Content types

  • text: a string of up to 4096 characters.
  • media_urls: an array of https URLs to an image, video, audio file or document.
  • template: {"name": "...", "language": "en", "components": [...]}. The template must exist in your account with status APPROVED, and language must be exactly the code the template was created with. See the example below.
  • location: {"latitude": "...", "longitude": "...", "name": "...", "address": "..."}, all four as strings.
  • interactive: reply-button, call-to-action and list messages.

Example: send a template

curl -u AUTH_ID:AUTH_TOKEN -H "Content-Type: application/json" \
  -X POST https://wbmsg-production.up.railway.app/v1/Account/AUTH_ID/Message/ \
  -d '{
    "src": "918269150291",
    "dst": "919876543210<918109760150",
    "type": "whatsapp",
    "template": {
      "name": "order_update",
      "language": "en",
      "components": [
        {"type": "header", "parameters": [{"type": "media", "media": "https://example.com/logo.png"}]},
        {"type": "body",   "parameters": [{"type": "text", "text": "Alex"}, {"type": "text", "text": "WB-1001"}]}
      ]
    }
  }'

Response, HTTP 202:

{
  "api_id": "5d935d21-46de-4566-9232-ac9c8a9ce569",
  "message": "message(s) queued",
  "message_uuid": ["426ed7b5-7b63-46b9-a659-39ac815a52cd", "cbe73c0d-..."]
}

One message_uuid is returned per recipient, in order. The call returns as soon as the message is queued. Delivery is reported by callbacks or by reading the message.

Template components. header takes a media parameter when the template has an image, video or document header. body takes one text parameter per {{1}}, {{2}}, ... placeholder, in order. Button parameters use "type": "button" with sub_type (quick_reply or url) and index.

5. Callbacks

Delivery status callbacks

WBMSG calls your callback URL each time a message changes state. The call is a form-encoded POST (or a query-string GET if you chose method=GET) with these fields:

FieldNotes
MessageUUIDThe id returned when you sent the message.
To, FromRecipient and your business number.
Typewhatsapp
Statusqueued, sent, delivered, read, failed or undelivered
ErrorCodeOnly present when Status is failed or undelivered. See error codes.
SequenceIncreases with each status change of the same message. Use it to ignore out-of-order calls.
MessageTimeTime of the status change.

Reply with any 2xx status within a few seconds. If your endpoint fails or times out, WBMSG retries after 60, 120 and 240 seconds.

Inbound messages

Messages your customers send to your WhatsApp number are forwarded to your inbound URL as a form-encoded POST with From, To, Text, Type and MessageUUID.

Verifying a callback

Every callback carries two headers:

  • X-WBMSG-Signature: the signature
  • X-WBMSG-Signature-Nonce: a random value used in the signature

Compute base64( HMAC-SHA256( key = your Auth Token, message = callback_url_without_query_string + nonce ) ) and compare it with the header. Reject the callback if they differ.

// Node.js
const crypto = require("crypto");
function valid(url, nonce, signature, authToken) {
  const base = url.split("?")[0];
  const expected = crypto.createHmac("sha256", authToken).update(base + nonce).digest("base64");
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature));
}
Callbacks are only sent to public https addresses. Private, internal and local addresses are refused.

6. Templates

All template calls use /WhatsApp/Template/{waba_id}/, where waba_id is your WhatsApp Business Account ID. Any other id returns 404. template_id is the id WhatsApp assigns to the template.

POST/WhatsApp/Template/{waba_id}/

Creates a template and submits it to WhatsApp for review.

FieldNotes
nameLowercase letters, digits and underscores.
languageFor example en or en_US. Use the same code when sending.
categoryMARKETING, UTILITY or AUTHENTICATION
componentsMust include a BODY. May also include HEADER, FOOTER and BUTTONS. An image, video or document header needs example.header_handle (a WhatsApp upload handle).
allow_category_changeOptional boolean. Lets WhatsApp re-categorize the template if it judges the category wrong.
curl -u AUTH_ID:AUTH_TOKEN -H "Content-Type: application/json" \
  -X POST https://wbmsg-production.up.railway.app/v1/Account/AUTH_ID/WhatsApp/Template/WABA_ID/ \
  -d '{
    "name": "account_update",
    "language": "en",
    "category": "UTILITY",
    "components": [
      {"type": "BODY",
       "text": "Hi {{1}}, your account setup was updated. Reference: {{2}}.",
       "example": {"body_text": [["Alex", "WB-1001"]]}},
      {"type": "FOOTER", "text": "Example Company"}
    ]
  }'

Response: {"api_id": "...", "status": "success", "message": "template submitted to meta for review", "template_id": "1098860766374195", "template_name": "account_update", "template_status": "PENDING", "template_language": "en", "template_category": "UTILITY"}

GET/WhatsApp/Template/{waba_id}/

Lists templates. Query: template_name (substring filter), limit (maximum 20), offset. Returns meta and objects, each with template_id, name, language, category and status.

GET/WhatsApp/Template/{waba_id}/{template_id}/

Returns one template with quality_score ({"score": "GREEN"} and similar), rejected_reason and the full components.

POST/WhatsApp/Template/{waba_id}/{template_id}/

Edits a template's components. The body has the same shape as create. name, language and category cannot change. Only approved, rejected and paused templates can be edited; the template returns to review. WhatsApp limits how often a template can be edited.

DELETE/WhatsApp/Template/{waba_id}/{template_id}/?name={template_name}

Deletes the template at WhatsApp and in WBMSG. name is required and must match the template. Returns 204. If WhatsApp refuses, the template is kept and you receive 502.

Template status values

StatusMeaning
PENDINGUnder review. Utility templates are often approved within minutes; others can take up to 24 hours.
APPROVEDReady to send.
REJECTEDNot approved. rejected_reason says why. Edit and resubmit.
PAUSEDPaused by WhatsApp after poor quality feedback. Cannot be sent until it recovers.
DISABLEDDisabled by WhatsApp. Cannot be sent.
IN_APPEALA review of a rejection or restriction is in progress.
FLAGGEDAt risk of being disabled because of quality issues.
LIMIT_EXCEEDEDThe template count or sending limit for the account was reached.
PENDING_DELETIONScheduled for deletion.
ARCHIVEDRemoved from use.

7. Error codes

ErrorCode appears on failed and undelivered messages, in callbacks and when reading a message.

CodeMeaning
310The phone number is not registered on WhatsApp.
330The message type is not supported.
340The template does not exist, is paused or is disabled.
350Template parameters do not match the template (wrong count or format).
360The WhatsApp Business account is locked or disabled.
370WhatsApp throughput or rate limit reached. Slow down and retry.
380More than 24 hours since the customer last wrote to you. Send an approved template instead.
6-digit numberWhatsApp's own error code, passed through unchanged (for example 131049). Details for any failure are in the WBMSG Message Log.
Error 131049. WhatsApp limits how many marketing templates one person receives from businesses in a period, and may decline to deliver the message. Do not retry immediately. Wait at least 24 hours before resending a marketing template to the same person. Utility templates are not affected, and messages sent inside an open 24-hour window are not counted.

8. WhatsApp rules to know

  • 24-hour window. Free-form messages (text, media, interactive, location) can only be delivered within 24 hours after the customer last messaged you. Outside the window, use an approved template.
  • Templates are reviewed by WhatsApp. Keep utility templates plainly transactional. Promotional wording makes WhatsApp classify them as marketing.
  • Opt-in. Only message people who agreed to hear from you on WhatsApp.
  • Quality. Low quality feedback can pause a template or limit your number. Watch quality_score on your templates.

9. Support checklist

When you contact support, include: the message_uuid or api_id, the time with its time zone, and your Auth ID. Never send your Auth Token.
